# TutorMatch

## Descripción

Aplicación móvil desarrollada en Flutter para conectar estudiantes con tutores.

## Características

- Registro e inicio de sesión
- Búsqueda de tutores
- Gestión de perfiles
- Chat entre usuarios
- Sistema de calificaciones

## Tecnologías

- Flutter
- Dart
- Firebase

## Instalación

flutter pub get

flutter run
