# 📚 TutorMatch

Aplicación móvil desarrollada en Flutter para conectar estudiantes con tutores.

## 🚀 Características

- Registro de usuarios
- Inicio de sesión
- Búsqueda de tutores
- Gestión de perfiles
- Sistema de calificaciones

## 🛠️ Tecnologías Utilizadas

- Flutter
- Dart
- Firebase
- Git
- GitHub

🎯 Objetivo
